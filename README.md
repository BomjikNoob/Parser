# ExsteamParser bot

Telegram-бот, который следит за маркетплейсами и присылает **новые объявления** в чат: фото, цена, продавец, ссылка. Через минуту после публикации, а не через час ручного обновления страниц.

**Площадки:** Vinted, Depop, Poshmark, Wallapop, Milanuncios, OLX, OfferUp (29 стран).

## Возможности

- **Задачи поиска:** площадка, страны, запрос (с минус-словами: `nike dunk -kids`), диапазон цены. Можно оставить запрос пустым и получать все объявления.
- **Только новое:** первая проверка запоминает текущую выдачу, дальше в чат приходит только то, что выложили после.
- **Фильтры по продавцу**, которых нет на самих площадках:
  - минимум отзывов или продаж;
  - минимальный возраст аккаунта;
  - только объявления с email или телефоном (ищутся в тексте объявления);
  - только частные продавцы, без магазинов.
- **Управление кнопками в чате:** пауза и запуск, карточка задачи со статистикой, скрытие продавца одной кнопкой.
- **⚡ Быстрый парс:** собрать N объявлений из выдачи сразу в `.txt`.
- **Прокси:** общий список с ротацией из `.env`, личные прокси на площадку или страну у каждого пользователя (`/proxy`).
- **Доступ:** бот отвечает только пользователям из `ALLOWED_USERS`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | меню и справка |
| 🔍 Новый поиск | создать задачу |
| 📋 Мои задачи | список задач, статус, фильтры |
| `/stop`, `/go` | остановить или запустить все задачи |
| `/hidden` | скрытые продавцы |
| `/proxy` | свои прокси |
| `/stats` | статистика |
| `/limit` | лимит карточек за проверку |

## Запуск

Нужен Python 3.12+.

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather и свой id в ALLOWED_USERS
python bot.py
```

Автозапуск на Windows (в фоне, при входе в систему, с перезапуском при падении):

```powershell
powershell -ExecutionPolicy Bypass -File autostart.ps1          # включить
powershell -ExecutionPolicy Bypass -File autostart.ps1 -Remove  # выключить
```

Логи пишутся в `parser.log`, данные хранятся в `parser.db` (SQLite).
